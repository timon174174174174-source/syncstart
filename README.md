# Общий старт

Комнаты с одновременным обратным отсчётом для кооперативных игр: все жмут «Готов», хост запускает отсчёт, у всех одновременно звучит «GO!».

## Возможности

- Комнаты по коду из 5 символов и прямой ссылке `?r=КОД`
- Статус «готов / не готов» у каждого участника
- Отсчёт 3 / 5 / 10 / 15 секунд, синхронизированный по времени сервера, со звуком
- Хост может:
  - **кикнуть игрока** (он может зайти снова) или **забанить** (не сможет вернуться в эту комнату)
  - **запустить отсчёт в любой момент**, даже если не все готовы
  - отменить отсчёт
  - закрыть комнату для всех
- Хост — всегда создатель комнаты: роль не передаётся, даже если он закрыл вкладку (комната ждёт его возвращения)
- Переподключение игроков без потери места в течение 30 секунд
- Ник обязателен
- Админка `/admin` (пароль из переменной `ADMIN_PASSWORD`; без неё админка выключена): активные комнаты, игроки, закрытие комнат

Комнаты хранятся в памяти и сохраняются на диск (`DATA_FILE`) при остановке сервиса, поэтому перезапуск их не теряет: игроки переподключаются автоматически.

У каждого игрока в списке видна задержка до сервера (на синхронность отсчёта она не влияет: момент старта назначается по часам сервера, а каждый браузер вычисляет поправку своих часов).

## Запуск

```bash
npm install
npm start          # http://localhost:8080
```

Или в Docker:

```bash
docker build -t syncstart .
docker run -d --name syncstart --restart unless-stopped -p 8080:8080 -v syncstart_data:/data -e ADMIN_PASSWORD=придумайте-пароль syncstart
```

Для HTTPS поставьте перед ним любой обратный прокси (например, Caddy) — WebSocket работает по пути `/ws`.

## Стек

Node.js + [ws](https://github.com/websockets/ws), фронтенд — один HTML-файл без сборки.
